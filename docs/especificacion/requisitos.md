# Requisitos del Proyecto: Instrumentos de Bronce

## 1. Requisitos funcionales
- RF1: El sistema debe mostrar una página de inicio con menú de navegación.
- RF2: El usuario debe poder acceder a la página de historia.
- RF3: El usuario debe poder ver la lista de instrumentos de bronce.
- RF4: El sistema debe mostrar información detallada de cada instrumento.
- RF5: El usuario debe poder acceder a la página de técnicas de interpretación.
- RF6: El sistema debe incluir un formulario de contacto.
- RF7: El formulario debe enviar los datos mediante método POST a un archivo PHP.
- RF8: El sistema debe mostrar un mensaje de confirmación al enviar el formulario.

## 2. Requisitos no funcionales
- RNF1: El sitio debe ser fácil de navegar.
- RNF2: El diseño debe ser claro, legible y coherente.
- RNF3: El sitio debe cargar en menos de 3 segundos.
- RNF4: El código debe estar organizado en carpetas (css, js, pages, php).
- RNF5: El proyecto debe estar versionado en GitHub.
- RNF6: El sitio debe ser compatible con dispositivos móviles.
