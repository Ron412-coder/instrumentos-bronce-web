# Proyecto Web: Instrumentos de Bronce

Este proyecto es una página web educativa dedicada a los instrumentos de viento-metal (bronce). 
Su objetivo es ofrecer información clara y organizada sobre su historia, características, técnica 
de interpretación y uso dentro de diferentes contextos musicales.

---

## 🎯 Objetivo del Proyecto

El propósito de este sitio web es:

- Presentar contenido educativo sobre los instrumentos de bronce.
- Facilitar la comprensión de su funcionamiento, técnica y mantenimiento.
- Servir como recurso para estudiantes, músicos y personas interesadas en la música.
- Practicar la estructura, documentación y desarrollo de un proyecto web completo.

---

## 🛠️ Tecnologías Utilizadas

El proyecto está desarrollado utilizando:

- **HTML5** – estructura del contenido.
- **CSS3** – diseño visual y estilos.
- **JavaScript** – interacción y comportamiento dinámico.
- **PHP** – procesamiento de formularios y lógica del servidor.
- **GitHub** – control de versiones y repositorio del proyecto.
- **Codespaces** – entorno de desarrollo en la nube.

---

## 📁 Estructura del Sitio Web

El sitio está compuesto por las siguientes páginas principales:

- **index.html** – Página de inicio y presentación del proyecto.
- **pages/historia.html** – Historia de los instrumentos de bronce.
- **pages/instrumentos.html** – Lista y descripción de los instrumentos.
- **pages/tecnica.html** – Técnicas de interpretación y mantenimiento.
- **pages/contacto.html** – Formulario de contacto (procesado con PHP).

Además, el proyecto incluye:

- **css/style.css** – Estilos globales del sitio.
- **js/script.js** – Scripts y funciones básicas.
- **php/procesar-form.php** – Lógica para recibir datos del formulario.
- **img/** – Imágenes relacionadas con los instrumentos.
