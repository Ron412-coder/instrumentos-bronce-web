# Análisis del Proyecto: Instrumentos de Bronce

## 1. Descripción del problema
Los estudiantes de música y personas interesadas en los instrumentos de viento-metal 
no siempre encuentran información clara, organizada y accesible sobre los instrumentos 
de bronce, su historia, características y técnicas de interpretación.

Este proyecto busca resolver esa necesidad creando un sitio web educativo y fácil de navegar.

---

## 2. Objetivo general
Crear una página web informativa sobre los instrumentos de bronce, que permita al usuario 
comprender su origen, funcionamiento, técnica y uso dentro de diferentes contextos musicales.

---

## 3. Objetivos específicos
- Presentar información clara sobre cada instrumento de bronce.
- Explicar técnicas básicas de interpretación.
- Mostrar la historia y evolución de estos instrumentos.
- Ofrecer un formulario de contacto para interacción básica.
- Practicar la estructura y documentación de un proyecto web completo.

---

## 4. Público objetivo
- Estudiantes de música.
- Músicos principiantes.
- Personas interesadas en instrumentos de viento-metal.
- Profesores que buscan material educativo.
- Usuarios curiosos que quieren aprender sobre música.

---

## 5. Alcance del proyecto
El sitio incluirá:
- Página de inicio.
- Página de historia.
- Página con lista de instrumentos.
- Página de técnicas de interpretación.
- Página de contacto con formulario.
- Documentación completa del desarrollo del proyecto.

No incluye:
- Audio profesional de instrumentos.
- Base de datos avanzada.
- Sistema de usuarios o login.

---

## 6. Justificación
Este proyecto permite aplicar conocimientos de programación web (HTML, CSS, JS, PHP) 
y al mismo tiempo crear un recurso educativo útil y bien estructurado.
